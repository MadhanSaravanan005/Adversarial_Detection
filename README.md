An automated image screening, defense, and monitoring system designed to detect and sanitize adversarial image perturbations (e.g., FGSM, PGD) before they reach downstream computer vision classifiers.

---

## 📖 Overview

Machine learning models, particularly deep convolutional neural networks (CNNs), are susceptible to adversarial examples—images subtly modified by imperceptible or structured perturbations that trick models into making confident, incorrect predictions. 

This project implements a multi-stage defensive firewall architecture following the **Detect → Defend → Decide** paradigm:
1. **Detect**: Rapid mathematical screening across five statistical and spatial heuristics.
2. **Defend**: Active sanitization through five defensive image transformations.
3. **Decide**: Tri-state security policy (`ALLOW`, `REVIEW`, `BLOCK`) with continuous background learning buffer.

---

## ⚠️ Problem

Deep neural network classifiers deployed in production image pipelines face two major security vulnerabilities:
1. **Model Vulnerability**: Standard models fail catastrophically under small, worst-case input perturbations ($\epsilon$-bounded noise) generated by gradient-based methods like Fast Gradient Sign Method (FGSM) or Projected Gradient Descent (PGD).
2. **Computational Overhead of Pure Deep Learning Defenses**: Running deep adversarial verification networks on every incoming image adds latency and GPU load that is often prohibitive for real-time applications.

---

## 💡 Solution

This system decouples anomaly detection from heavy neural network inference by utilizing:
- **Fast Heuristic Screening ($<50$ms)**: An ensemble of five lightweight mathematical methods that detect distribution asymmetry, spatial variance, and channel anomalies on CPU without GPU overhead.
- **Input Sanitization**: Transforming suspicious images through frequency and rank filters (JPEG, Gaussian blur, median filtering, resizing, bit-depth reduction) to destroy high-frequency perturbation energy.
- **Selective Verification**: Routing only ambiguous cases to secondary verification while allowing clean images to pass unimpeded.

## 🔍 Detection Methods

The primary operational detector combines five mathematical heuristics:

1. **Color Channel Consistency ($25\%$ weight)**:
   - Evaluates standard deviation across mean channel intensities: $\sigma_{\text{color}} = \text{std}(\mu_R, \mu_G, \mu_B)$.
   - Perturbations that disproportionately target specific color channels trigger elevated scores.
2. **Spatial Texture Variance ($20\%$ weight)**:
   - Computes standard deviation across grayscale pixel intensities: $\sigma_{\text{gray}} = \sqrt{\frac{1}{N} \sum (I_i - \bar{I})^2}$.
   - Additive adversarial noise increases high-frequency pixel-to-pixel roughness.
3. **Distribution Skewness ($25\%$ weight)**:
   - Computes the third standardized moment of pixel intensities: $\gamma_1 = \mathbb{E}\left[\left(\frac{I - \mu}{\sigma}\right)^3\right]$.
   - Gradient attacks disrupt the natural symmetric histogram distribution of clean natural images.
4. **Shannon Entropy Density ($20\%$ weight)**:
   - Measures information randomness over 256 intensity bins: $H = -\sum_{i=1}^{256} p_i \log_2(p_i + \epsilon)$.
   - Structured noise and pseudo-random perturbations increase overall disorder and entropy.
5. **Chromatic Saturation Ratio ($10\%$ weight)**:
   - Analyzes the saturation channel in HSV color space: $S = 1 - \frac{\min(R,G,B)}{\max(R,G,B) + \epsilon}$.
   - Flags unnatural saturation spikes or artificially uniform saturation planes.

**Ensemble Aggregation**:
$$\text{Risk}_{\text{heuristic}} = \left(0.25 \cdot S_{\text{color}} + 0.20 \cdot S_{\text{texture}} + 0.25 \cdot S_{\text{skew}} + 0.20 \cdot S_{\text{entropy}} + 0.10 \cdot S_{\text{sat}}\right) \times 100$$
The resulting score is bounded: $0 \le \text{Risk} \le 100$.

## ⚔️ Adversarial Attacks

This system focuses on gradient-based and noise perturbation attacks evaluated on CIFAR-10 resolution ($32 \times 32$):
- **Fast Gradient Sign Method (FGSM)**:
  $$x_{\text{adv}} = x + \epsilon \cdot \text{sign}\left(\nabla_x \mathcal{L}(\theta, x, y)\right)$$
  One-step $L_\infty$-bounded attack that adds uniform-magnitude sign perturbations across pixels, caught primarily by distribution skew and texture variance.
- **Projected Gradient Descent (PGD)**:
  $$x^{t+1} = \Pi_{x + \mathcal{S}}\left(x^t + \alpha \cdot \text{sign}\left(\nabla_x \mathcal{L}(\theta, x^t, y)\right)\right)$$
  Multi-step iterative attack creating concentrated localized high-frequency patterns, detected via entropy density and spatial variance.

## 🛡️ Defense / Sanitization

The defense engine implements five restorative transformations:

1. **JPEG Compression Defense**: Lossy discrete cosine transform (DCT) quantization discards high-frequency coefficients where perturbation energy is concentrated.
2. **Gaussian Blur Defense**: Spatial convolution with a $3 \times 3$ Gaussian kernel ($\sigma=1.0$) attenuates fine additive noise.
3. **Median Filter Defense**: Non-linear rank filter ($3 \times 3$ or $5 \times 5$) replaces each pixel with the local median, removing extreme noise spikes while preserving sharp structural boundaries.
4. **Spatial Resizing Defense**: Downsampling via bilinear interpolation to $50\%$ dimensions followed by Lanczos reconstruction to $32 \times 32$ breaks pixel-aligned perturbation grids.
5. **Bit-Depth Reduction (Quantization)**: Quantizing 8-bit color depths (256 levels) to 4 bits (16 levels) eliminates low-magnitude perturbations falling within quantization steps.

*Note: Sanitization significantly reduces adversarial noise energy but does not mathematically guarantee complete removal against adaptive attacks.*

## 🧠 CNN Component & Checkpoint Status

- **Architecture Present**: The convolutional architecture (`AdversarialDetectionCNN`: 3 Conv layers, BatchNorm, Dropout, 2-class binary output) is defined in `backend/background_trainer.py`.
- **Trained Checkpoint Status**: **No pre-trained weights file (`.pth`/`.pt`) is included in the repository** (removed in commit `3e82116` to respect repository limits).
- **Graceful Degradation**:
  - The system checks for `models/robust_model.pth` at startup.
  - When absent, the system explicitly reports `checkpoint_loaded: false` and `active_pipeline: "Heuristic Detection + Sanitization"`.
  - Untrained/random CNN weights are never used for inference.
  - The system runs 100% of detections via the verified 5-method heuristic ensemble.
- **Loading Custom Weights**: Drop any compatible PyTorch weights into `models/robust_model.pth`. The system will automatically detect the checkpoint on startup and activate Stage 2 neural network verification.

- ✅ **Fully Runnable Locally**: Zero external cloud or GPU requirements.

## ⚖️ Limitations

1. **Missing Checkpoint**: No pre-trained `.pth` weights are bundled. The CNN stage gracefully degrades to Stage 1 heuristic screening.
2. **CIFAR-10 Scale ($32 \times 32$)**: Optimized for standard small-scale image benchmarks; high-resolution inputs are downscaled via Lanczos interpolation before processing.
3. **Attack Assumptions**: The heuristics assume perturbation energy alters statistical distribution moments or spatial variance. Purely semantic adversarial attacks (e.g., physical patch or lighting manipulations) may not trigger pixel-level distribution anomalies.
4. **Sanitization Detail Trade-off**: Aggressive filtering (e.g., bit-depth reduction $\le 3$ bits or heavy Gaussian blur) dampens perturbations but slightly softens fine textures.
